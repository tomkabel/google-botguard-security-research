## 3. PART I: The Historical Landscape — Probabilistic Client-Side Attestation (2010–2024)

### 3.1 Methodology: Systematic Literature Search

- **PRISMA explicitly not employed** (rationale: designed for empirical meta-analyses of clinical trials, not qualitative taxonomic synthesis of vendor whitepapers, IETF drafts, and grey literature)
- Transparent documentation of databases searched, search queries, date range, inclusion criteria
- Source corpus: 75 publications

### 3.2 Five Analytical Ideal Types

- **Type I:** Point-in-Time VM Attestation
- **Type II:** Stateful Behavioral Telemetry  
- **Type III:** Behavioral Biometrics & Sensor Telemetry
- **Type IV:** Platform/OS-level Anonymous Attestation (PATs)
- **Type V:** Hardware-Anchored Determinism (DBSC, FIDO2)
- Each ideal type documented with: mechanism, cost imposed under EF and OS, structural ceiling, representative systems

### 3.3 The Hybrid Reality: Production Systems Do Not Respect Ideal Types

- Turnstile = Type I + Type II fusion (VM as delivery mechanism for telemetry)
- DataDome = Type II + Type III fusion
- Arkose Labs = Type I auxiliary + Type II/III
- These are not edge cases; taxonomy value is analytical vocabulary, not clean classification

### 3.4 The L1-L4 Diagnostic Framework

- **L1a/L1b:** Environmental Introspection (Static + Dynamic)
- **L2:** Code Obfuscation
- **L3:** Execution Traps
- **L4:** Chronometric Integrity
- Each subsection includes: mechanism, why it fails under Operator Synthesis
- Diagnostic summary table: all 4 layers collapse under OS

### 3.5 The Temporal Arms Race: A Historical Case Study

- Formerly presented as novel contribution; now explicitly framed as historical
- Why the race was already structurally unsound even before VLMs
